# L'Atelier des Dés — prototype

Jeu de dé-building pour 2 à 6 joueurs, jouable dans le navigateur contre des bots.

- `index.html` : le jeu complet.
- `config.js` : l'adresse du serveur Google qui enregistre les parties des playtesteurs.

Les parties terminées sont envoyées (pseudo + déroulé de la partie, sans e-mail ni adresse IP) dans un Google Sheet pour aider à équilibrer le jeu.
